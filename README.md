## Описание
Бот позволяет создавать, просматривать и удалять напоминания.

## Команды
| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/new` | Создать напоминание |
| `/list` | Список напоминаний |
| `/delete <id>` | Удалить |
| `/stats` | Статистика |

## Форматы даты
- `2025-12-31 18:00`
- `завтра 15:30`
- `через 2 часа`
- `через 30 минут`

## Локальный запуск
```bash
pip install -r requirements.txt
echo "TELEGRAM_BOT_TOKEN=ваш_токен" > .env
